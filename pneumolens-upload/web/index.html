How should I read this?

The map highlights regions influencing the model’s score. Its native resolution is only 7 × 7. Borders and text can influence the model too. A plausible heatmap does not prove a medically valid explanation.

Colors are normalized separately for each image and class. They cannot be compared as confidence.

What these results do—and don’t—tell us

This is one dataset with 624 test images and one training seed. The test set was already examined for the baseline; fine-tuning comparisons reuse it and are exploratory. The split uses filename-derived groups, not independently verified patient records. No external clinical validation has been performed.

BEHIND THE MODEL

From pixels to perspective.

A transparent pipeline. An inspectable explanation. Clear boundaries.

01

Preserve the image.

Resize with aspect ratio preserved, pad to 224 × 224, and apply ImageNet normalization. The same preprocessing is used for training and inference.

02

Make a prediction.

A ResNet-18 initialized on ImageNet predicts the two dataset classes. The baseline trains its linear head; the follow-up trains the last residual block too.

03

Trace the influence.

Differentiate a class logit with respect to the final block’s activations. Average gradients, weight the activation channels, then keep positive contributions.

04

Look critically.

Remove the input padding and align the map with the scan. Inspect both successes and errors. The 7 × 7 map shows model influence, not infected tissue.

THE MATH, MADE EXPLICIT

Gradient-weighted class activation.

CAMc = ReLU( Σk αkc Ak )

Each α is the spatial average of the gradient of the selected class logit with respect to an activation channel A. Every heatmap is normalized separately.

DESIGNED FOR RESEARCH

Limits are part of the explanation.

  • NORMAL is a dataset label, not an assurance of health.
  • The model cannot verify that an upload is an appropriate X-ray.
  • A convincing overlay can accompany an incorrect prediction.
  • JPEG and PNG only; DICOM windowing is not supported.
  • Uploads are processed by the local Python server in memory and are not saved. Hosting would transmit them to that server.

QUESTION THE HEATMAP

What changes when learned weights are removed?

In this recorded experiment, we selected the first two validation filenames per class, then randomized the classification head and last residual stage. The maps change, but randomized weights can still produce plausible overlays. This four-image check cannot establish medical correctness.
